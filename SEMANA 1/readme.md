## Información general
Este repositorio contiene la documentación, scripts y evidencias del inventario de hardware realizados durante la primera semana de clases. El objetivo es documentar los resultados que obtuve al obtener la información del hardware (CPU, RAM, discos y red) tanto en mi computadora física con Windows como en la máquina virtual con Linux.

---

## Contenido del Repositorio

- **comandos.md**: Comandos para revisón del estado del equipo en Windows y Linux.
- **inventario.ps1**: Script en PowerShell para información de hardware en Windows.
- **inventario.sh**: Script en Bash para información de hardware en Linux.
- **inventario_MSI.txt**: Resultado dado por el script en el sistema host (Windows 11).
- **inventario_linux.txt**: Resultado dado por el script en el entorno virtual (VirtualBox).
